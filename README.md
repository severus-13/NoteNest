# NoteNest
A semester-wise study platform for students to store notes, assignments, presentations, and question papers — organized by subject and module, with a calm academic look (navy slate, blue accents, study icons).

## How to use

Works on phones, tablets, and desktops — open in any modern browser (Chrome, Safari, Firefox, Edge).

1. Open `index.html` in your browser (or run `python -m http.server 8080`).
2. **Create** a unique 5-character username (e.g. `alan1`) or **Sign in** with one you already created — no password. Usernames cannot be repeated on this device.
3. Pick a semester, subject, category, and module (1–4).
4. Upload and search files — everything stays on your device.

## Features

- Unique 5-character usernames — create once, sign in later; files are private per user
- 8 semesters with editable subject lists (per user)
- Notes, Assignments, PPT, Question Paper categories
- 4 modules per category
- Editable semester timetable
- KTU student portal link
- File search per module
- **Focus & refresh timer** — Custom focus length (1–180 min), then a 5 min break with wellness tips
